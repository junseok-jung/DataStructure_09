과제 09: 모든 정점 쌍의 최단경로 탐색



1. **정점 수 (10개)**: `MAX_VERTICES 10`으로 고정하여 0~9번 정점 생성 확인 (`Vertices : 10`)
2. **간선 수 (20개)**: `TARGET_EDGES 20` 조건으로 유효 간선 20개 생성 및 출력 확인 (`Edges : 20`)
3. **간선 가중치 부여**: `(rand() % 100) + 1`을 통해 모든 간선에 1~100 사이의 양의 정수 가중치 부여 확인
4. **자기 루프 및 중복 간선 배제**: `u != v && g->weight[u][v] == INF` 조건으로 자기 루프 및 중복 간선 생성 차단 확인
5. **연결 그래프 여부**: 그래프 생성 후 `dfs()` 기반 `isConnected()`로 모든 정점 방문 여부를 검사하여 연결 그래프만 확정
6. **45개 정점 쌍 출력**: `u < v` 조건의 이중 반복문으로 중복 없이 45개 정점 쌍 모두 출력 확인 (`Total vertex pairs : 45`)
7. **실제 최단경로 출력**: `next_vertex` 배열로 경유 정점을 추적하여 `Path : u -> ... -> v` 형태의 전체 이동 경로 복원 확인
8. **최단거리 계산 정확성**: Floyd-Warshall 알고리즘으로 경로상 간선 가중치들의 합이 최소인 `Distance` 계산 확인
